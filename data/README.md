# データ管理ルール

## このディレクトリの目的
実験で収集した心拍数・HRVデータ、および主観評価の記録を管理する。

---

## 個人情報・生データの取り扱い

### 基本方針
- 収集したデータには心拍数・HRVという生体情報が含まれるため、取り扱いには慎重を期す
- 実名・学籍番号等の個人を特定できる情報は、データファイルに含めない
- 被験者本人の同意を得た上でデータを収集する

### 匿名化ルール
- 被験者の識別には `subject_01`, `subject_02` 等のIDを使用する
- 実名とIDの対応表は、外部に公開しない（リポジトリには含めない）

---

## 本番データの共有範囲の制限

- 実際に収集した生体データ（本番データ）は、チームメンバー間でのみ共有する
- GitHubに本番データをpushする場合は、匿名化済みであることを確認してから行う
- 外部発表・資料に使用するデータは、被験者の同意を改めて確認する
- 万が一、個人を特定できるデータが混入した場合は、すぐにチームリーダーに報告し、git履歴からの削除を検討する

---

## このリポジトリに置くデータ

### 置いてよいもの
- サンプルCSV（架空の値や完全に匿名化されたデータ）
- 実験のフォーマットテンプレート（ヘッダー行のみのCSVなど）
- 集計済みの統計量（平均・標準偏差など、個人が特定できない形式）

### 置かないもの
- 実名・学籍番号が含まれるデータ
- 本番の生データ（収集したままの状態のもの）
- HealthKitからエクスポートした生ファイル（`export.xml` など）

---

## サンプルデータのフォーマット（予定）

```csv
subject_id,date,time,heart_rate_bpm,hrv_sdnn_ms,stress_score,subjective_rating,notes
subject_01,2025-01-01,09:00,62,45,48,2,安静時
subject_01,2025-01-01,14:00,78,28,71,4,発表直前
```

| カラム名 | 説明 |
|---------|------|
| `subject_id` | 被験者ID（匿名） |
| `date` | 収集日（YYYY-MM-DD） |
| `time` | 収集時刻（HH:MM） |
| `heart_rate_bpm` | 心拍数（bpm） |
| `hrv_sdnn_ms` | HRV（SDNN, ms） |
| `stress_score` | 算出されたスコア（0〜100） |
| `subjective_rating` | 主観評価（1〜5） |
| `notes` | 状況のメモ |
