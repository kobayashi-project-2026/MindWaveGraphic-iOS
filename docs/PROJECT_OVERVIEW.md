# プロジェクト概要：Mind Wave Graphic

## 背景と動機
現代の日常生活において、ストレスや緊張の度合いを客観的に把握する手段は限られている。主観的な「なんとなく緊張している」という感覚を、生体データを使って数値・グラフィックとして可視化できれば、自己理解や状態管理に役立てられると考えた。

Apple Watchは心拍数とHRVをリアルタイムで取得できる身近なデバイスであり、HealthKitを通じてiPhoneアプリから利用できる。このプラットフォームを活用して、心理状態の「ゆらぎ」を可視化するアプリを開発する。

## プロジェクトの目標
1. 心拍数とHRVから「緊張不安定度」（0〜100）を算出する計算モデルを設計・実装する
2. SwiftUIを用いて、スコアを直感的に伝えるグラフィック表現を実装する
3. 実際のデータを収集し、主観評価と照合することでモデルの妥当性を検証する

## 技術スタック
| 要素 | 選択 | 理由 |
|------|------|------|
| プラットフォーム | Apple Watch + iPhone | HealthKit経由でHRVを取得できる |
| 言語 | Swift | iOS/watchOS開発の標準言語 |
| UIフレームワーク | SwiftUI | 宣言的UIで実装しやすい |
| データ取得 | HealthKit | HeartRate / HRV(SDNN) を取得できる |
| 初期データ | ダミーデータ | HealthKit連携前の動作確認に使用 |

## 対象ユーザー
- このアプリ自身が被験者となり、自分たちのデータで検証する（まずは開発チーム内での自己実験）

## スコープ外（将来検討）
- スマホカメラを用いたrPPG（遠隔心拍測定）によるスマホ1台完結
- RMSSD等の他のHRV指標の利用
- 他ユーザーへの展開・個人差補正の高度化

## 想定するデモの流れ
1. アプリを起動する
2. 心拍数・HRVの現在値（または直近の平均値）が表示される
3. 「緊張不安定度スコア」がグラフィックで表示される
4. 平常時と緊張時でスコアが変化することを確認できる

## 進捗状況

### フェーズ1：ダミーデータMVP（実装済み・実機確認待ち）
- `StressScoreCalculator.swift` に計算式を実装した
- `MindSampleScenario.swift` に3つのダミーシナリオ（平常時・軽い緊張・強い緊張）を定義した
- UIをMind Wave風のダークUIに全面刷新した（詳細は下記「UI方向性」を参照）
- HealthKit連携なしで計算式とUIの動作確認ができる状態になった
- **次の作業：** Xcodeでシミュレータ／実機を使ってUIの表示を確認する

### フェーズ2：HealthKit連携（土台追加済み・実接続待ち）
- `HealthKitManager.swift` を追加した（心拍数・HRV読み取り・平均値取得）
- `MindWaveViewModel.swift` を追加した（HealthKit実データとデモデータの切り替え）
- ユーザー向けUIから「平常時 / 軽い緊張 / 強い緊張」の手動選択感を除去した
- シナリオ切り替えは `LiveWaveView` の Debug セクション（折りたたみ式）に移動した
- HealthKit未接続時は `デモデータで表示中` を表示し、アプリが落ちないようにした
- **次の作業：** Xcode で HealthKit Capability を追加し、実機でデータ取得を確認する

## UI方向性（フェーズ1にて整備）

### コンセプト
- アプリ内表示名：**Mind Wave**（プロジェクト名は引き続き Mind Wave Graphic）
- キャッチコピー：「いまの自分を、流れで知る。」
- Apple Watch の心拍・呼吸・静寂感の世界観を持つ、落ち着いたメンタルケア系UI

### デザイン方針
- ダーク背景（黒〜濃紺グラデーション）
- 青白い発光アクセントカラー
- 半透明のダークカード（角丸16pt）
- 文字は白・薄いグレー中心
- ストレス状態は青（落ち着き）→橙（軽い緊張）→赤（強い緊張）で示す

### 画面構成（4タブ）
| タブ | 内容 |
|------|------|
| ホーム | タイトル・Apple Watch接続カード・準備チェック・セッション開始ボタン |
| ライブ | 波形アニメーション（TimelineView + Canvas）・スコアカード・シナリオ切り替え |
| ガイド | 呼吸ガイド・発光パルスリング・一時停止/終了ボタン（現段階はダミー） |
| 履歴 | セッション履歴カード・ミニ波形サムネイル（現段階はダミーデータ） |
