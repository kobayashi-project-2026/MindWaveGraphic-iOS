## 3. シミュレーターで確認した画面（`build/ai-e2e/`、Git 管理外）

| 画面 | 端末 | 結果 |
|---|---|---|
| 結果画面の「もこりんと結果を見る」 | iPhone 17 Pro | 既存の結果の下に 1 つだけ表示 |
| 結果の説明（最初の吹き出し） | iPhone 17 Pro / SE | デモデータの注意・心拍・スコア・HRV 不足を表示。「端末内の説明（AIではありません）」 |
| 「どういう意味？」「前と比べる」「次にできること」→「試してみた？」 | iPhone 17 Pro / SE | 選んだ選択肢は消え、確認は 1 回。デモは過去と比べない |
| 記録の詳細 →「もこりんと振り返る」 | iPhone 17 Pro | 試合の記録で「ウォーミングアップ」の提案、根拠は「場面に『試合・競技前』を選んでいたから」 |

画面確認で見つけて直した点: 会話がないのに提案の根拠が「〜と話していたから」になっていた → 画面で選んだ場面を根拠に／デモデータの注意が最初の吹き出しに出ていなかった → 先頭に表示。

DEBUG 用の起動設定（Release では無効）: `GUIDE_PHASE=result`、`MW_COMPANION=result|review`、`MW_COMPANION_TAPS=meaning||compare||advice`、`MW_SEED_DEMO_RECORD=1`（記録が 0 件のときデモの記録を 1 件追加）。
