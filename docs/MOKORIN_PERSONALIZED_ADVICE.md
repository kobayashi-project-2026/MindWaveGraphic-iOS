# もこりんの個別改善提案

作成: 2026-11-05 / 実装: `MindWaveGraphic/MindWaveGraphic/Mokorin/MokorinAdviceEngine.swift`、`MokorinResultExplainer.swift`
テスト: `Tests/MindWaveCoreTests/MokorinAITests.swift`（「もこりん / 個別提案」「結果の説明」）

## 1. 目的と範囲

- 本人が話した状況と、存在する記録・測定値だけをもとに、**任意で試せる具体的な行動**を 1〜2 個提案する
- 日常のセルフケア・準備行動の支援に限る。**診断・病名・治療・服薬の話はしない**。HR・HRV から気持ちや病気を断定しない
- 一般論を並べない。提案には必ず「何に基づくか（basis）」を添える

## 2. 使う情報と分け方

| 区分 | 内容 | 出どころ |
|---|---|---|
| 確認済みの事実 | 本人が話した場面・身体状態・予定の言葉（`situationNote`）・主観的な緊張・疲れの言葉 | 測定前の会話（`MokorinSessionMemory`。メモリのみ） |
| 確認済みの事実 | 記録にある心拍・緊張スコア（アプリの既存の計算値）・HRV（ある場合だけ）・本人の感覚（自己申告）・信頼度・デモデータか | `GuideSnapshot`・`GuideSessionRecord` |
| 確認済みの事実 | 同じ場面の過去の記録（デモデータを除く） | `GuideHistoryStore` |
| AI（端末内の規則）による解釈 | 「下がった → 落ち着く方向に変化した**可能性**」「上がった → いろいろな理由が考えられる」 | `MokorinResultExplainer` |
| 改善提案 | 話題ごとの行動＋身体状態に応じた注意 | `MokorinAdviceEngine` |

測定前の会話は、**同じ流れ（測定開始の 6 時間以内）の結果にだけ**使う。記録の振り返りでは使わない（そのときの会話とは限らないため）。

## 3. 提案の決め方

1. 深刻な体の症状の言葉（胸の痛み・息苦しさ・気を失いそう・強いめまい・止まらない動悸・しびれ・「死にたい」「消えたい」など）があれば、**提案をやめて**相談を案内する:
   「体のつらさが強いときは、もこりんだけでは判断できないよ。無理をせず、近くの人や医療機関に相談してね。急に具合が悪くなったときは、迷わず救急（119）を呼んでね。」
   結果・振り返りの会話では、この言葉が入力されたら外部 AI へ送らず、すぐにこの案内を出す
2. 疲れ・睡眠不足を話していたら、休憩の提案を先にする
3. 話題（`MokorinTopic`）ごとの準備の提案
4. 走ってきた・階段・カフェインなど測定値に影響しうる身体状態なら、測り直し・結果の見方の注意
5. 同じ提案を重ねず、最大 2 個

### 話題の決め方（既存の場面の列挙値は増やさない）

本人の言葉を優先し（訂正では後ろに出てきた言葉）、なければ既存の場面から決める。

| 話題 | 言葉の例 | 既存の場面（ContextScene / MeasurementScene） |
|---|---|---|
| presentation（発表） | 発表・プレゼン・スピーチ・ゼミ | interview / speech |
| interview（面接） | 面接・面談 | interview |
| exam（試験） | 試験・テスト・受験・検定 | work / study |
| sports（試合） | 試合・大会・競技・レース・部活 | sports |
| firstMeeting（初対面） | 初対面・初めて会う・知らない人 | important（または other） |
| important（大切な予定） | デート・大切な・大事な・約束 | important / social |
| work（作業） | 仕事・作業・勉強・会議・課題 | work / meeting |
| rest（安静） | — | calm / daily |
| unknown | — | other |

## 4. 具体例

| 状況 | 提案 | 1 回だけの確認 |
|---|---|---|
| 面接前 | 最初に聞かれそうな質問への答えを、一度だけ声に出して言ってみよう。 | 声に出してみた？ |
| 発表前 | 冒頭の30秒だけ、声に出して練習しておくと話し始めやすくなるかもしれないね。 | 冒頭、言ってみた？ |
| 試験前 | 始まったら、まず解けそうな問題を1つ見つけてから進めよう。 | — |
| 試合前 | ウォーミングアップはもう終わった？まだなら、いつもの準備から始めよう。 | いつもの準備、できた？ |
| 大切な予定 | 会ったら最初に話したいことを1つだけ決めておくと、始めやすいよ。 | — |
| 初対面 | 最初のあいさつと、聞いてみたいことを1つだけ用意しておこう。 | — |
| 作業・勉強 | 最初の25分だけ集中する、と区切って始めてみよう。 | 区切って始められた？ |
| 疲れ・睡眠不足 | 少し休憩できそう？無理をせず、今できることから考えよう。 | 少し休めた？ |
| 走った・階段の直後 | 動いた直後は心拍が上がりやすいよ。測り直すなら、数分座って息が落ち着いてからにしてみよう。 | — |
| 理由のわからない緊張 | 理由がはっきりしなくても大丈夫。ゆっくり3回呼吸して、今できることを1つだけ決めよう。 | — |
| 落ち着いている | 今の落ち着いた状態の記録も、あとで比べるときの参考になるよ。（行動は求めない） | — |

確認（「試してみた？」）は提案のあとに **1 回だけ**。「試してみた」「あとでやる」のどちらでも、それ以上は聞かない。

## 5. 結果の説明の規則（`MokorinResultExplainer`）

- 心拍: 前後の差が −3 bpm 以下なら「下がっている。落ち着く方向に変化した可能性」、+3 以上なら「上がっている。いろいろな理由が考えられる」、それ以外は「大きな変化はない」
- 緊張スコア: アプリの既存の計算値をそのまま表示（±5 以上の変化だけ解釈を添える）。計算方法は変更していない
- HRV: 値がある記録だけ説明する。ない場合は「HRV はこの記録では取れていない」と伝え、心拍とスコアだけで説明する
- ガイド後の値がない場合は、前後の比較をしない
- デモデータは「実際の体の状態ではない」と最初に伝え、過去の記録とは比べない
- 信頼度が 50% 未満なら「参考程度に」
- 過去との比較: 同じ場面・デモ以外・心拍がある記録だけ。直近の 1 件と比べ、3 件以上あれば「N 回のうち M 回で下がった（数えただけで、傾向とは言い切れない）」と回数だけを伝える。測定条件が違うと値も変わりやすいことを添える
- 記録がなければ「まだ比べられない。測るたびに比べられるようになる」

## 6. 制限事項

- 提案は端末内の規則によるもので、外部 AI が作ったものではない（画面に「端末内の説明（AIではありません）」と表示）
- 提案の効果の評価（試したあとに測り直して比べる）は、測定条件の違いが大きいため今回は行っていない。会話で「少し変化はあった？」と聞くだけ
- 試したかどうかは保存しない（保存先を増やさないため）
- 外部 AI による提案の言い換え（自然さの向上）は、測定値を送る必要があるため、本物の利用者認証と測定値の送信への同意がそろうまで行わない
