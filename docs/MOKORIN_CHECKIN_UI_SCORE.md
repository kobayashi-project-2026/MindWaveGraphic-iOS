## 1. 会話（STEP 0〜6）

- 最初のあいさつ: 「こんにちは！今日もおつかれさま！今日はどんな感じ？まずは今の自分の状態を一緒に確認してみよう！」＋最初の質問 1 つ（緊張を決めつけない）
- 項目（`MokorinCheckIn`）: 睡眠・活動・体調・場面・時期・気持ち・緊張の強さ S0（0〜100）・気になること（複数）・体の変化（複数、「特にない」と排他）・してみたいこと。出どころ（本人・HealthKit・推定）、更新時刻、確かさ、答えたくない項目を保持
- 次の質問は `nextSlot()` で動的に選ぶ（答え済み・答えたくない・尋ねた項目は尋ねない。必要な 4 項目＝場面・気持ち・緊張の強さ・してみたいこと がそろえば終了、上限 7 問。体調が悪いときは質問を止めて休息）
- 1 つの発言から複数の項目を抽出（`CheckInExtractor`。訂正は後ろを優先）。外部 AI があれば AI の抽出（`result.check_in`）を優先し、端末内の抽出で補う
- 選択肢は質問ごとに最大 3 つ＋「ほかの答え・答えない」（全部の選択肢、複数選択、スキップ）
- 「一つ前の会話へ戻る」（画面左上）: 直前の答えを取り消し、会話・集めた情報・推薦を元に戻す
- 深刻な症状の言葉（胸の痛み・息苦しさなど）は外部 AI へ送らず、端末内で医療機関・救急への相談を案内
- 既存の場面・身体状態（MeasurementContext）へは既存の値だけで対応（列挙値は追加していない）

API（`/v1/context-assist`）: 要求 `current.check_in`・`current.next_slot`、結果 `check_in`（いずれも追加。古いアプリ・サーバーと互換。未知の値は採用しない）。

## 2. 改善方法の推薦（`MokorinMethodAdvisor`）

本人の希望を最優先し、最大 2 つ・理由つき。A 緊張が強い → 呼吸＋筋弛緩／B 考えすぎ → 心配ごとの整理＋冒頭の練習・対話／C 切り替え → グラウンディング＋ストレッチ・小休憩／D 分からない → 状態の確認＋対話／E 自信 → 強みの振り返り＋回答・冒頭の練習。睡眠不足・強い疲れは休憩を先に。息苦しさがあるときは息を長く止める 4-7-8・BOX を推薦しない。体調が悪いときは休息のみ。
ガイド（タイマーとグラフィック）があるのは既存の 3 つの呼吸法だけ。ストレッチ・筋弛緩・グラウンディングなどは、もこりんが手順を表示する（既存コードにガイドがないため）。

## 3. 試作スコア（`PrototypeTensionScore`）

`S(t) = clip(S0 + 0.77×(HRt−HR0) − 0.57×(SDNNt−SDNN0), 0, 100)`、モデル `subjective_hr_sdnn_prototype_v1`。検証用の試作表示式で、医学的に検証された推定器ではない（資料の GalaxyPPG 回帰式とは別物）。
既存の `StressScoreCalculator` は変更していない（`stress_score_calculator_v1` として区別）。欠損・古い値（HR 60 秒・SDNN 600 秒）・異常値・基準より前の値は補正に使わず、状態（complete / partial_hr_only / partial_sdnn_only / subjective_only / unavailable）で示す。S0 がなければスコアを出さない。送信用 JSON の evaluation は欠損を null で出す。
結果画面: ガイド前を基準（HR0・SDNN0）、ガイド後を時刻 t として表示。S0 は会話で聞いた強さ、なければ体感入力から。保存形式は変えていない（表示のみ）。

### 試作スコアとグラフィック
会話で S0 を聞いたあとは、最初の計測値を基準（HR0・SDNN0）にして、ホームのグラフィック・小さなもこりん・知らせを試作スコアで動かす（「試作スコア 70・本人の評価のみ（生体情報なし・参考）」のように状態を表示）。S0 がないときは従来の計算のまま。結果画面はガイド前を基準・ガイド後を時刻 t。値がない項目は補わない。
